# Homebrew Tap for Tide

Homebrew tap for [Tide](https://github.com/code-with-current/tide) — a local-first agentic coding companion.

## Install

```sh
brew install --cask code-with-current/tap/tide
```

Or tap first, then install:

```sh
brew tap code-with-current/tap
brew install --cask tide
```

## Updating

The cask is updated automatically on each [Tide release](https://github.com/code-with-current/tide/releases) via GitHub Actions.
